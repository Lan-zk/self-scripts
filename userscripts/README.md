# userscripts — 浏览器用户脚本

Tampermonkey（油猴）脚本集合。每个子目录是一个独立的脚本项目，包含脚本本体（`*.user.js`）和各自的说明。

## 目录

| 子目录 | 脚本 | 说明 |
|---|---|---|
| [zhixingli/](zhixingli/) | 职行力自动刷课助手 | 职行力学习平台（u.exexm.com）课程自动播放、评价与挂机守护 |

## 通用说明

- 安装：Tampermonkey → 管理面板 → 实用工具 → 导入文件，或新建脚本后粘贴 `*.user.js` 全部内容。
- 更新脚本版本时**先删除旧版**再安装新版，避免两个实例同时运行互相干扰。
- 各脚本的详细用法、配置项与排查方法见其子目录内的 README。
